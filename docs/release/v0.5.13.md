# Munin v0.5.13

Munin v0.5.13 makes recall more useful for session recovery by attaching a
compact, structured summary to each matching session.

## Highlights

- `munin recall --format json` now includes a `session_summary` object for
  matching session rows.
- Each session summary has five concise bullet points that cover the session's
  goal, concrete work, verification, blockers or caveats, and useful follow-up.
- Summary quality metadata records the schema version, source session id,
  source event counts, and whether the summarizer had enough evidence.
- Command counts separate total commands from successful, failed, and unknown
  commands without promoting command logs into the human summary text.
- Prompt scaffolding, wrapper tags, path dumps, and low-signal handoff text are
  filtered before they can dominate recall summaries.
